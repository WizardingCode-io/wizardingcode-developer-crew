# Research

## When

Read this before research for an item is planned or run, and before its result is judged: a question on the code, the documentation, what changed lately, good practice, a market, a flow of a real site, what users say, or the academic literature. The method's rules are below, and three other skills hold a verification, an evidence map and a choice between candidates. The depths, the two new moments of a research, the freshness window of each kind and the writing to a project's memory are not built: this skill gives the rules a run follows, not its size, and no skill of the four writes to a memory.

## Rules written from the sources

Each row is a rule the crew wrote in its own words from one of the sources the user gave on 2026-11-15, named in the second cell. No gate of the crew rules by a row of this table and a reviewer names none as a defect: where a row disagrees with a row of the crew's rules, the crew's rule holds. No sentence of a source is copied, no source is installed by this skill, and a session opens none.

| Rule | Source |
| :- | :- |
| A source that failed, was cut short or was never set up is reported as such, and only a source that answered with nothing is called quiet. | `last30days` |
| A source that matters is read whole before it is relied on, since the lines a search returns are not the source. | `deer-flow` |
| Whoever researches for another is kept from the project's own papers, so that what the project believes cannot come back as a finding. | `bmad` |
| What speaks against the subject is searched for on purpose, not left to turn up. | `deer-flow` |
| Every place a finding was met is cited, and the finding itself is told once. | `knowledge-work` |
| No further round is run once a round has brought nothing new. | `bmad` |
| A query is as exact in time as the question it serves, so that a question about this week is not answered by a search of the whole year. | `deer-flow` |
| Where a current state is claimed from a source, the age of that source is said with it. | `knowledge-work` |
