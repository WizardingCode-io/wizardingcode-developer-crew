# Sources of End to end and API

Each section is a subject of the team's definition (`docs/specs/2026-11-15-qa-team-design.md`, section 3) with its sources as the definition's row holds them, one a line. The research opened each page and read its title, not the page end to end; a line that says a page was not opened, or that names a paid book, names nothing that was read. A line is where a subject is read and no line is a rule. The addresses are provenance: they are never opened by the session, and nothing in this file is a step for a session to take.

## End to end

- The crew's rules (`plugins/core/skills/crew/references/gate.md`, the plugin's Playwright fixture `plugins/core/e2e/playwright.mjs`)
- the documentation of the project's e2e runner: Playwright's "Best Practices" (https://playwright.dev/docs/best-practices), "Locators" (https://playwright.dev/docs/locators), "Auto-waiting" (https://playwright.dev/docs/actionability) and "Trace viewer" (https://playwright.dev/docs/trace-viewer), "Cypress best practices" (https://docs.cypress.io/app/core-concepts/best-practices), "Laravel Dusk" (https://laravel.com/docs/dusk) and Pest's "Browser Testing" (https://pestphp.com/docs/browser-testing), the Testing Library (https://testing-library.com/)
- Martin Fowler's "Broad Stack Test" (https://martinfowler.com/bliki/BroadStackTest.html) and "Page Object" (https://martinfowler.com/bliki/PageObject.html)
- the Google Testing Blog's "Just Say No to More End-to-End Tests" (https://testing.googleblog.com/2015/04/just-say-no-to-more-end-to-end-tests.html)
- the framework's documentation on HTTP and browser tests, as Laravel's "HTTP Tests" (https://laravel.com/docs/http-tests)
- what the project declares of its environment (compose, Makefile, scripts)
