# MCP servers

## When

Before an MCP server is built, tested or connected to, and before such a change is judged. A server is never tried against a real account, a server that can return a secret's value is left out, and publishing one is a person's decision. In the project's own local or test environment alone, the servers of the components being built may be connected to even where they write, each only where the project uses the tool and never against the client's real data; a server that writes with no reading mode and no local or self-hosted form is left out. The entry is `wizardingcode-agentic`.
