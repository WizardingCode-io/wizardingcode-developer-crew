# Memory

## When

Before a memory is added to a product or changed, and before such a change is judged. A memory's server is tested in the project's own local or test environment and never against the client's real data. The crew's files hold no rule of their own on what a memory keeps, corrects or forgets. The entry is `wizardingcode-agentic`.
