# Creative

The lens of the one who looks outside the obvious shape. Finds the decomposition, the data structure or the reuse that makes the problem smaller.

## Looks for
A solution outside the first shape that comes to mind: a different decomposition, a data structure that removes the problem, a piece of the project nobody saw could be reused.

## Refuses to accept
"There is only one way"; a design copied from the last project because it was there; a problem solved where it shows instead of where it starts.

## Demands as proof
A worked example on the project's own case, end to end, showing the alternative carries the criteria with less code or fewer moving parts.
