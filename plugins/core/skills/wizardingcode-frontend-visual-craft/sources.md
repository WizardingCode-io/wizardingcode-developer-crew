# Sources of the Visual craft skill

One line per address the skill cites: the address, its title, what it is, and the date the research for the frontend team's definition read the page itself (`docs/specs/2026-11-16-frontend-team-design.md`, section 3). A page read in part, or a study read by its abstract, says so on its line. A source known only from a search summary is not here and no rule cites it. The addresses are provenance: nothing in this file is a step for a session to take. The research's notes stay on the machine that made them.
