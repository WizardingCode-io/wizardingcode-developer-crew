# Sources of the info-product sales page playbook

One line per address the playbook cites: the address, its title, what it is, and the date the research for the frontend team's definition read the page itself (`docs/specs/2026-11-16-frontend-team-design.md`, section 1). A source known only from a search summary is not here and no rule cites it. The pages were read through a fetch that returns a model's extraction of the page, and the two papers as PDFs: a figure was seen in the page's text and was not copied by a person. The research's notes stay on the machine that made them. The addresses are provenance: nothing in this file is a step for a session to take.
