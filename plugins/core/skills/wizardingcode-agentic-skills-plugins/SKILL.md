# Skills and plugins

## When

Before a skill or a plugin is written, and before an outside set of skills enters a solution, and before such a change is judged. No set enters unread. A set's hooks, its servers that act on an account and its vendor's install scripts stay out; a skill of it that acts on an account enters with its set, and when such a skill is used a deploy to production and any command that deletes or changes a real resource are a person's decision; a skill that publishes or approves stays out. The entry is `wizardingcode-agentic`.
