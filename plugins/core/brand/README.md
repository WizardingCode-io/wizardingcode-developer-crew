# Brand assets

Byte-identical copies of the WizardingCode lockup, its reverse and the "Overlap" mark from `docs/brand/` of the repository, shipped with the plugin so the reports the engine renders carry the brand (SP7 §13.2). As ADR 0001 says, they identify WizardingCode and are not covered by the repository's MIT licence for reuse on other products. The brand book and design system they come from live with the brand.
